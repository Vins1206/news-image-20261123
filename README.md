A program that draws one 1024x1024 newspaper front page summing up the world's news of Monday 23 November 2026 — COP31 collapses in Antalya with no fossil-fuel deal, the Gulf war escalates as Iran hits US bases in Bahrain and tankers are struck in the Strait of Hormuz, a Russian drone flattens a flat block near Kyiv, AI goes on trial at the UN and in Seoul, and the world in brief — and writes it to `/output/entry.png`. Pure Python standard library, no network, deterministic: two runs write byte-identical output.

## Run it

```sh
python3 main.py
```
